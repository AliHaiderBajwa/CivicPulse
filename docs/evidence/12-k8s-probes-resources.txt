=== H3: probe configuration (startup / liveness / readiness) ===
-- backend
startup:  path=/health port=http failureThreshold=30
   liveness:  path=/health port=http period=10
   readiness: path=/ready port=http period=5
-- frontend
startup:  path=/healthz port=http failureThreshold=30
   liveness:  path=/healthz port=http period=10
   readiness: path=/healthz port=http period=5
-- postgres (exec pg_isready — liveness must not route via backend)
liveness=["pg_isready","-U","civicpulse","-d","civicpulse"] readiness=["pg_isready","-U","civicpulse","-d","civicpulse"]
Rationale: liveness = /health (process alive, NO database call); readiness = /ready (DB-dependent). Killing a slow DB must not restart pods.
